**Claude Code 插件集市**是经过精选的插件集合，用于使用新技能、命令和
Agent 扩展 Claude Code。插件集市允许团队共享工具，使每位开发者无需手动设置即可获得相同的能力。

**f5-sales-demo 插件集市**提供专为 [f5-sales-demo](https://github.com/f5-sales-demo)
文档平台构建的插件 — 该生态系统由 20 多个仓库组成，使用共享构建流水线将 Astro/Starlight 网站发布到 GitHub Pages。

## 工作原理

1. **添加插件集市**到 Claude Code — 这会将其注册为插件源
2. 从集市**安装插件** — 每个插件都会将技能和命令添加到您的 Claude Code 会话中
3. **使用工具** — 插件会根据上下文自动激活，或者您可以直接调用其命令

## 可用插件

| 插件 | 类别 | 描述 |
| --- | --- | --- |
| [f5xc-docs-tools](/marketplace/en/plugins/f5xc-docs-tools/) | 生产力 | 用于文档仓库的 MDX 内容验证和审查工具 |
| [f5xc-sales-engineer](/marketplace/en/plugins/f5xc-sales-engineer/) | 生产力 | Sales Engineer 角色框架 — 演示执行、演示汇报、问答及环境管理 |

## 快速开始

添加插件集市并安装文档工具插件：

```text
/plugin marketplace add f5-sales-demo/marketplace
/plugin install f5xc-docs-tools@f5-sales-demo-marketplace
```

参见[快速入门](/marketplace/en/getting-started/)获取完整指引。

## 架构

插件集市是一个包含一个或多个插件的 Git 仓库。每个插件将技能、命令和 Agent 打包为一个可安装单元。

```text
Marketplace (marketplace.json)
└── Plugin (plugin.json)
    ├── Skills (SKILL.md)
    │   └── References (data files)
    ├── Commands (.md)
    └── Agents (.md)
```

- **Marketplace** — 注册表。列出可用插件及其用于发现和安装的元数据。
- **Plugin** — 可安装单元。包含一个或多个技能、命令或 Agent。
- **Skill** — Claude 根据当前任务自动激活的上下文知识。
- **Command** — 用户直接调用的斜杠命令（例如 `/review-mdx`）。
- **Agent** — 自主处理复杂多步骤任务的专用子 Agent。
