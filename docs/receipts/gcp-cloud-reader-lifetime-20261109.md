# GCP cloud reader lifetime qualification

The installed cloud and serial reader now checks the original operation deadline
before and after authentication and every cloud request. Expiry during a reply
retains the available body as incomplete evidence. Final reads require the
original apply identity and its already admitted fixed five-minute reserve;
cloned authority, foreign invocations and changed budgets refuse before
Google authentication. The admitted ADC uses the existing owned, no-follow
reader and exact file/parent comparison.

Five new lifetime cases failed before implementation. They now pass alongside
the eight preserved final-dispatcher cases and an elapsed-reserve case in
isolated test processes with a synthetic monotonic clock. These mocks cannot affect real Python readers or
other suites. The real Python reserve tests preserve the host clock and both
original windows. Same-byte input tests explicitly change timestamps instead
of assuming a filesystem timestamp resolution below two milliseconds.

Validation passes: 968 top-level shared tests and 4,251 assertions, all fourteen
isolated clock cases, Terraform typechecking, three runtime builds and the
changed-scope privacy gate. A fresh authenticated source composition completed two default SDK reads and
two real Compute absence reads against the same original Terraform invocation,
including its fixed final reserve. Its reviewed empty plan and final no-change
plan have zero managed resources. Independent inspection found all sixteen
original process groups absent. This verifies source composition with existing
authentication, not ordinary installed-tool or cloud apply acceptance.

Exact-head CI ran on managed runners and reported failures in the original
expiry/timestamp fixtures and Python structure/module resolution. The fixture
repairs are included here; Python repair and fresh passing CI remain required.
No failing check is bypassed. The default full installed capture controller,
cloud apply and numeric insert attribution, live guest capture, networking,
lifecycle, traffic, two-hour expiry, ordinary installed runtime, required review,
publication and published installation remain open. See the preserved
[full acceptance matrix](gcp-issue-1559-acceptance.md).
