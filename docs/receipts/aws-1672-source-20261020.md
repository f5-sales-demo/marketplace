## Candidate and behavior

AWS 2.3.1 uses development runtime 23.9.3 and minimum runtime 23.8.0.
The minimum increased because command argv, preview and evidence controls are
required by the adapter. Registration discovery remains at 23.8.0.

The data-only adapter declares exact commands using shared execution argument
builders, complete identity fields, twelve-row EC2/S3 previews, readable columns
and byte units, and selected guarded Customer Edge summaries. Valid structured
results supply expanded evidence once; malformed and opaque results retain
automatic evidence and completion warnings. Cloud-init source and bootstrap
references are excluded from custom call sections.

Focused execution fixes retain equals-form output flags, report nonzero help
exits as failures, propagate help cancellation, distinguish prefixes from
zero-byte objects, retain large byte counts and object-key spaces, and reject
malformed nonempty S3 listings. Infrastructure mutation guards are preserved.

## Source evidence

Failing behavioral regressions were captured before production changes. The
latest and exact-minimum AWS suites each pass 173 tests with 348 assertions on
macOS. Command tests compare display and executor argv and reconstruct literal
arguments using harmless Bash/Zsh commands, including empty strings, quotes,
metacharacters, Unicode and newlines. Biome and changed-scope PII enforcement
and audit pass. Tracker/ownership tests pass 11 tests with 36 assertions.

Canonical discovery reports 23 plugins, 324 surfaces and 2,757 active tasks.
Fingerprint reconciliation reopens affected AWS/shared acceptance while
preserving historical receipts and Salesforce qualification.
