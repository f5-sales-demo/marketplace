## Source 1.2.1 changes

The review command resolves the shipped `skill://brand:reviewer`. Status now
provides an exact Bash/Zsh-compatible local reference collector run from the
resolved physical installed plugin root. It reports scope, independent reference
states, counts, declared palette and font families, warnings and completion.
Missing, empty, unreadable, symlinked or malformed references remain incomplete;
unknown counts remain null. Review and asset verification remain false.
No fetch, authentication, file write or service startup is performed.

Review guidance preserves caller scope, unreadable files, incomplete checks,
severity counts and literal corrections. Twelve findings appear initially and
remaining evidence appears once. The agent uses the same guidance and severity
names. Runtime layout, themes, symbols and progress remain in xcsh.

Five pre-fix behavioral tests failed against the shipped 1.2.0 guidance. Current
regressions execute the exact collector with harmless temporary directories in
Bash and Zsh, verify the 45 declared palette rows and both font families, and
check read-only behavior, explicit unknowns and incomplete outcomes. Original
failures and raw fixtures remain private.
