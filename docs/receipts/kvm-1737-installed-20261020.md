## Installed contracts and host observations

Separate installed-module checks on published 23.9.5 loaded all five tools,
verified each exact effective controller argument array and reconstructed it through
harmless Python execution under Bash and Zsh. Literal quotes, substitutions,
a newline and an empty string were preserved. Readiness/status/destroy declared
empty parameters; deploy/reconcile retained supplied scope. Every tool's partial
result remained pending. Complete safe details and original operator guidance
appeared once in the declared expanded view. These checks establish installed
adapter contracts, not native model execution or controller mutation acceptance.

Mac's actual installed integration probe returned `unavailable` with
`dependency_missing` before invoking the Ubuntu controller. Ubuntu's installed
controller independently returned successful envelopes with `setup_required` for
both `--json readiness --params '{}'` and `--json setup status --params '{}'`;
the Ubuntu 24.04 x64 platform check passed. These read-only observations did not
apply setup or modify infrastructure. Raw host evidence remains private. They
establish the observed prerequisite state, not a healthy accepted deployment.

The initial attempt to apply newer argv assertions to runtime 23.5.1 failed,
confirming that the minimum API-loading lane does not establish newer presentation
metadata. It remains preserved separately from the passing stable lane. A broken
fresh-worktree dependency symlink caused an initial tracker-load failure; correcting
the symlink restored all ten tracker tests. Neither failure is presented as success.
