# Azure presentation source qualification: #1677

Scope: Azure 4.6.1 source changes. Parent #1593 and campaign #1579 remain open.

## Installed baseline

Published runtime 23.9.3 and installed Azure 4.6.0 on Mac produced 96 native frames for synthetic subscription identity and thirteen resource rows. Raw captures remain private at `private:presentation-1579/azure-baseline-20261020`.

Individual buffer checks recorded 36 failures. Twenty-four collapsed resource frames exposed a three-row preview. Expanded resource output duplicated the table and fallback evidence. The other twelve failures were narrow-width literal wrapping; they do not establish lost identity or row data. No service, setup or authentication action was executed.

## Changed behavior and regressions

- Subscription identity retains all selected fields, including false, zero and empty values.
- Resource collections use twelve-row previews and provide complete expanded rows once.
- Graph/activity metadata exposes scope, coverage and pagination by default.
- CE inventory, discovery, plan, checkpoint, status, diagnostics and cloud-init use domain summaries without fabricated multi-command invocations. Malformed envelopes retain automatic fallback.
- CLI command declarations share execution builders. Explicit group-list actions preserve list semantics and tag flags; output equals flags remain effective. Help rejects embedded option tokens and forwards cancellation.
- CE status keeps missing F5 BGP/route evidence unknown and exposes unavailable Azure read coverage separately from zero returned records.
- Expanded calls withhold cloud-init source and singular/plural bootstrap references.

Observed failing regressions were retained privately before fixes. Focused execution/argv, privacy, malformed-evidence, pagination and shell-copy cases now pass on Mac. Bash and Zsh roundtrips use a harmless function and preserve spaces, quotes, metacharacters, empty arguments, Unicode and newlines.

Mac Azure suite: 284 tests, 701 assertions, zero failures against development runtime 23.9.3. Independent minimum-runtime lane: 284 tests, 701 assertions, zero failures with exact runtime 23.8.0. Catalog, ownership, canonical tracker and manifest checks pass; discovery stays 23.8.0.

Ubuntu independent minimum-runtime checks also passed. The complete plugin runner and hermeticity checks passed with CI Bun 1.4.2 and an isolated PyYAML 6.0.3 test environment. The first broad run failed because the default Python interpreter lacked PyYAML; that failure log is retained privately. The pinned Bun archive digest and all plugin lockfile formats were verified.
