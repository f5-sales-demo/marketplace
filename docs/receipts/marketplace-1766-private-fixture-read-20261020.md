# Exact private fixture-read admission

Campaign #1579; prerequisite #1766 for executed content qualification.

The guarded observer previously admitted installed guidance and exact shipped
shell calls but could not read synthetic MDX fixtures outside the installation.
Two behavioral regressions failed before implementation. The runner now accepts
explicit fixture declarations with a physical private directory, exact regular
file path, SHA-256 digest and full-file read arguments. No broad read selector,
credential path or delegation capability is added.

Admission rejects traversal, indirect paths, nonprivate roots, changed contents,
extra arguments, partial selectors and unbounded timeouts. Each reviewed fixture
is admitted once with a fresh dispatch identity. Actual start/end arguments are
joined independently of callback order; changed files are rejected again before
returned evidence is accepted. Duplicate, mismatched and unadmitted results cannot
become captures. Fixture results use the workflow lane and retain path/digest
provenance separately from shipped-guidance captures.

Focused runner, observer, ownership and lifecycle checks pass 43 tests with 268
assertions. Minimum 23.5.1 and stable 23.9.5 compatibility checks each pass 40 tests with 251 assertions;
discovery remains 23.8.0. Raw failures and results remain private in
`fixture1766-*-mac.log`. These source checks do not prove installed executed review,
rendered pagination, publication or service acceptance. Merge green, then execute
scoped synthetic reviewer cases and inspect their actual conclusions and evidence
on each host before accepting dependent content gates. Preserve Salesforce
qualification, retired Devcontainer rows and prior receipts.
