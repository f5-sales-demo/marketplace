# GCP cleanup CLI transport

Issue: [marketplace #1559](https://github.com/f5-sales-demo/marketplace/issues/1559).

GCloud 1.7.76 exports compiled cleanup observations through the shared native
executor without process signals. The adapter accepts only exact read arguments
derived from the original Terraform intent. It pins the interpreter and CLI,
account, configuration and project, refuses credential alternatives, and checks
source inputs and independent original reader closure around execution. It
retains partial capture and final native completion separately and preserves the
original failed executor claim. Commands retain sixty-second limits, fifteen-second
startup bounds and a separate five-minute final capture reserve.

Original cloud descriptions, firewall insert identity joins and observer image,
service-account and interface observations reuse the same domain argument
builders. Native execution returns bounded private stdout and stderr, including
empty stderr. The transport grants no cloud ownership, delete authority or
permission to replay an uncertain submission. Existing reviewed teardown and
durable recovery remain required.
