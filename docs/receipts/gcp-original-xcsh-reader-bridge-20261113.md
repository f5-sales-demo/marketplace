# GCP original xcsh reader bridge qualification

Issue: #1559. Delivery: draft PR #1698. Full acceptance remains incomplete.

The typed bridge now runs against the real shared signal-free executor, an
original source-issued runner plan and the published xcsh 15.16.2 provider.
The fixture uses pinned Python 3.15, Terraform 1.17.2 and Bun 1.4.4 with a
synthetic loopback API. It establishes no cloud or ordinary installed acceptance.

The successful fixture retains the original parent and reader identities,
private readiness, the exact target creation receipt and independently verified
process group closure. One mock create is followed by a no-change plan, a
reviewed delete-only plan, one delete, empty destroy and independent absence.
No process signal is sent. Copied results cannot acquire private evidence access.

Earlier failures remain retained. Lock declaration and private artifact checks
refused before apply. Repeated full binary checks exhausted the fixed startup
window; the unreleased original parent exited and its group closed. The fixture
now performs full digest checks at admission, before release and final capture,
with continuous file identity checks while polling. The existing full byte check
API remains unchanged. The new identity API retains inode, timestamps including
ctime, owner, mode, size, parent, descriptor and watcher checks after successful
full digest admission. Its production runtime adoption remains unqualified.

Actual provider execution exposed two observer ordering gaps. A candidate can
exit before its first witness, and an owned sink can open before the first claim
is written. Both intervals now retain incomplete evidence and grant no target
coverage. Completion still requires every exact original target receipt. Changed
identities, foreign claims, replacement processes and lost witnessed evidence
remain refusals. The general Google candidate monitor retains its strict default.

Three failing-first bridge tests now prevent concurrent reader openings and
retain synchronous factory and invocation failures through the terminal path.
Failure receipts preserve private original attribution and false completion;
failure to retain evidence remains a separate error. A claimed scope cannot
start a replacement reader. Failed flags and historical locks are preserved.

Focused verification includes 101 Python observer, reader and process tests,
plus 23 bridge, identity and diagnostic tests. Three runtime bundles, Biome,
Python lint and the original Terraform TypeScript configuration pass. Additional
current-source family checks and final fixture evidence are recorded separately
in the private attempt ledger.

The default installed capture factory remains held. Original Site/token/JWT,
VM/NIC/insert/audit joins, same-provider refresh across expiry, ordinary Ubuntu
`bun dev`, native and Terraform lifecycle/network/traffic campaigns, independent
cleanup and restoration, required review/CI, publication and user installation
remain gates. Frozen collectors, historical evidence and immutable v12.3.1 assets
are unchanged. q12's exact failure cause remains unknown.
