Qualify deals, track evidence, and generate deal reviews and editable Excel workbooks.

<Badge text="Productivity" variant="tip" /> <Badge text="Content" variant="note" />

Plugin identifier: `meddpicc`. [Source and release metadata](https://github.com/f5-sales-demo/marketplace/tree/main/plugins/meddpicc/.xcsh-plugin/plugin.json).

## Prerequisites

Follow [Get started](/marketplace/en/getting-started/) for shared installation
requirements. Allow about 5 minutes for an initial check after setup.

- Authorized deal evidence and a private working directory.
- Bun when you run the bundled command-line engine.
- Salesforce access only if you use Salesforce-backed evidence.

## Set up

Install from your shell after registering the marketplace:

```bash
xcsh plugin install meddpicc@f5-sales-demo-marketplace
```

This content plugin has no integration setup or authentication step. Start a
fresh xcsh session to load its skills and commands.

## Use the plugin

MEDDPICC covers Metrics, Economic buyer, Decision criteria, Decision process,
Paper process, Identify pain, Champion, and Competition. Each element scores
0–4; the overall percentage is the sum divided by 32, multiplied by 100.

| Task | Command |
| --- | --- |
| Start a guided qualification | `/meddpicc:qualify-deal` |
| Add meeting notes or other evidence | `/meddpicc:update-deal` |
| Inspect score changes and forecast risk | `/meddpicc:deal-review` |
| Test champion evidence | `/meddpicc:champion-test` |
| Build a mutual action plan | `/meddpicc:build-map` |

Deal JSON is the source of truth. The engine validates and scores it, generates
a formula-driven workbook, and previews workbook edits before applying them
back to the deal. Ask for engine help before choosing its options. In the
installed xcsh Bash tool, run:

```bash
bun xcsh://plugin/meddpicc/file/engine/cli.ts --help
bun xcsh://plugin/meddpicc/file/engine/cli.ts read --help
```

These resource paths resolve inside xcsh. In a source checkout, use
`bun plugins/meddpicc/engine/cli.ts --help`. Run help separately from execution
arguments; malformed or mixed help requests return an error.

## Verify

Validate the deal and check that scores cite supporting evidence. Preview
workbook changes before applying them, then regenerate to confirm consistency.

## Clean up

Apply your organization's retention policy to deal JSON, Markdown reports,
and workbooks. These local files are unencrypted; keep authorized customer
data in private storage and out of Git or public artifacts.

For plugin removal, follow
[Remove a plugin](/marketplace/en/getting-started/#remove-a-plugin).
