Review colors, typography, logos, icons, terminology, and accessibility against F5 brand guidance.

<Badge text="Documentation and web" variant="tip" /> <Badge text="Content" variant="note" />

## Requirements

- Content or visual assets to review.
- The applicable F5 brand references.

## Install

```bash
xcsh plugin install brand@f5-sales-demo-marketplace
```

Follow [shared installation and restart instructions](/marketplace/en/getting-started/#install-a-plugin).

## Review an asset

Run `/brand:review-brand` with the asset path or a bounded file pattern. Ask for specific color, typography, logo, terminology, and accessibility findings, then correct the reported inconsistencies.

Use the applicable brand references to resolve reported inconsistencies. Check
accessibility as part of the content review, including contrast, readable text,
and meaningful image descriptions.

## Check the result

Reopen the changed artifact at its intended size. Confirm the approved logo,
colors, typography, and readable contrast.
