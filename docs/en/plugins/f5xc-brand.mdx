Plugin identifier: `brand`. [Source and release metadata](https://github.com/f5-sales-demo/marketplace/tree/main/plugins/brand/.xcsh-plugin/plugin.json).

## Prerequisites

Follow [Get started](/marketplace/en/getting-started/) for shared installation
requirements. Allow about 5 minutes for an initial check after setup.

- Content or visual assets to review.
- The applicable F5 brand references.

## Set up

Install from your shell after registering the marketplace:

```bash
xcsh plugin install brand@f5-sales-demo-marketplace
```

This content plugin has no integration setup or authentication step. Start a
fresh xcsh session to load its skills and commands.

## Use the plugin

Run `/brand:review-brand` with a path or file pattern. The `reviewer` skill
reports inconsistencies; `guardian` provides brand standards, and
`visual-content` guides the creation of visual assets.

Use `brand-operator` for a scoped review that needs reference lookups. Check
accessibility as part of the content review, including contrast, readable text,
and meaningful image descriptions.

## Verify

Reopen the changed artifact at its intended size. Confirm the approved logo,
colors, typography, and readable contrast.

## Clean up

Remove disposable previews and unused asset variants. Retain approved source
assets in their intended repository.

For plugin removal, follow
[Remove a plugin](/marketplace/en/getting-started/#remove-a-plugin).
