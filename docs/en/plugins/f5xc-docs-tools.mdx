Review Markdown with JSX (MDX) content for syntax, metadata, imports, and page structure.

<Badge text="Documentation and web" variant="tip" /> <Badge text="Content" variant="note" />

## Requirements

- A repository with MDX documentation.
- Its component definitions and content conventions.

## Install

```bash
xcsh plugin install docs-tools@f5-sales-demo-marketplace
```

Follow [shared installation and restart instructions](/marketplace/en/getting-started/#install-a-plugin).

## Review selected pages

Open the repository and run `/docs-tools:review-mdx` with the MDX paths you want reviewed. Ask for findings grouped by severity, with the affected file and an actionable correction.

The review checks frontmatter, syntax, imports, components, images, structure, and exports.

Use `/docs-tools:docs-tools-status` to check whether the workspace contains
MDX content and an Astro/Starlight project.

## Check the result

Apply the reported fixes, rerun the review, and build the site. Confirm that
imports resolve and each changed page renders.
