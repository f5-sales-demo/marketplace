Install the stable F5 Herdr fork and work with its terminal workspaces, tabs, panes, and agents.

<Badge text="Development" variant="tip" /> <Badge text="Integrated" variant="note" />

Plugin identifier: `herdr`. [Source and release metadata](https://github.com/f5-sales-demo/marketplace/tree/main/plugins/herdr/.xcsh-plugin/plugin.json).

## Prerequisites

Follow [Get started](/marketplace/en/getting-started/) for shared installation
requirements. Allow about 5 minutes for an initial check after setup.

- A supported 64-bit Linux, macOS, or Windows host.
- HTTPS access to the stable F5 Herdr manifest and release.
- A managed pane or explicit live pairing for terminal control.

## Set up

Install from your shell after registering the marketplace:

```bash
xcsh plugin install herdr@f5-sales-demo-marketplace
```

Check readiness. If setup is required, run the human setup flow in an
interactive terminal:

```bash
xcsh plugin status herdr
xcsh plugin setup herdr
```

## Use the plugin

Setup installs the stable F5 distribution from verified release evidence.
Installation doesn't bind an external worker to a terminal session.

Inside a managed pane, discover the installed surface:

```bash
herdr --help
herdr status server --json
herdr pane current --current
```

Use the `herdr` skill to inspect workspaces, tabs, panes, and recognized coding
agents. Prefer `--current` or an explicit live identifier. External workers need
a consumer-bound lease from the intended pane; socket discovery or copied
environment values don't establish control authority.

Check named server capabilities before using advanced commands. For graphics,
inspect the pane's advertised support rather than assuming the outer terminal's
capabilities.

## Verify

Confirm the installed binary and stable release evidence. From the intended
pane or paired worker, check server status and live pane identity. Plugin
readiness alone doesn't prove a control lease.

## Clean up

Close only panes or sessions you created for the task. Keep existing servers
and user sessions running; plugin removal doesn't authorize stopping them.

For plugin removal, follow
[Remove a plugin](/marketplace/en/getting-started/#remove-a-plugin).
