<Badge text="Documentation and web" variant="tip" /> <Badge text="Content" variant="note" />

## Requirements

- A documentation repository in the F5 sales-demo fleet.
- Docker for the local preview workflow.

## Install

```bash
xcsh plugin install docs-pipeline@f5-sales-demo-marketplace
```

Follow [shared installation and restart instructions](/marketplace/en/getting-started/#install-a-plugin).

## Find ownership and preview a page

Ask which repository owns the change you need: page content, navigation, build configuration, or managed workflow. Provide the affected file and intended result. Then run `/docs-pipeline:preview-docs` in the content repository.

Content belongs in its source repository; shared navigation and typography belong in `docs-theme`, builds in `docs-builder`, and managed workflows in `docs-control`. Resolve ownership before editing.

Use `content-author` for page structure and MDX conventions. Run
`/docs-pipeline:preview-docs` for a local container preview, or
`/docs-pipeline:docs-pipeline-status` to inspect pipeline readiness.

## Check the result

Build the changed content and open its rendered pages. For publication,
confirm that the deployment used the intended content commit.
