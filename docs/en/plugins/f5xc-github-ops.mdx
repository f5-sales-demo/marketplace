Plugin identifier: `github`. [Source and release metadata](https://github.com/f5-sales-demo/marketplace/tree/main/plugins/github/.xcsh-plugin/plugin.json).

## Prerequisites

Follow [Get started](/marketplace/en/getting-started/) for shared installation
requirements. Allow about 5 minutes for an initial check after setup.

- GitHub CLI, `gh`, and Git.
- An authenticated account with access to the intended repository.
- The repository's contribution and host-routing instructions.

## Set up

Install from your shell after registering the marketplace:

```bash
xcsh plugin install github@f5-sales-demo-marketplace
```

Check readiness. If setup is required, run the human setup flow in an
interactive terminal:

```bash
xcsh plugin status github
xcsh plugin setup github
```

A reviewed direct install can authorize bounded setup. Dependency installation
and upgrades don't grant that setup authorization.

## Use the plugin

| Task | Native tool |
| --- | --- |
| Coordinate workflow stages | `github_workflow` |
| Create an issue or pull request | `github_issue_create`, `github_pr_create` |
| Enable auto-merge or update a branch | `github_pr_auto_merge`, `github_pr_update_branch` |
| Prepare or retire a worktree | `github_worktree_prepare`, `github_worktree_cleanup` |

Use `workflow-lifecycle` for issue, branch, implementation, verification,
review, merge, and cleanup stages. `upstream-contribution` covers upstream work;
`github-index` routes tasks to typed tools, `github-ops`, or `cli-operator`.
General GitHub CLI tools also support issue, pull request, diff, search, and
failed-check inspection.

Setup can collect account and associated-email profile evidence. Review the
selected account and collection fields. Repository governance remains advisory
in the tool result; follow the repository's actual delivery requirements.

## Verify

Compare workflow evidence with the intended repository and branch. Confirm
the pull request reaches `MERGED` and required checks pass before reporting delivery.

## Clean up

Inspect tracked and ignored files before removing the task worktree. Delete
only a local branch whose pull request is confirmed merged. Preserve unrelated
worktrees, branches, and authentication.

For plugin removal, follow
[Remove a plugin](/marketplace/en/getting-started/#remove-a-plugin).
