Plugin identifier: `terraform`. [Source and release metadata](https://github.com/f5-sales-demo/marketplace/tree/main/plugins/terraform/.xcsh-plugin/plugin.json).

## Prerequisites

Follow [Get started](/marketplace/en/getting-started/) for shared installation
requirements. Allow about 5 minutes for an initial check after setup.

- Terraform CLI.
- Access to the relevant HashiCorp Registry provider documentation.
- A working directory with the intended Terraform configuration.

## Set up

Install from your shell after registering the marketplace:

```bash
xcsh plugin install terraform@f5-sales-demo-marketplace
```

Check readiness. If setup is required, run the human setup flow in an
interactive terminal:

```bash
xcsh plugin status terraform
xcsh plugin setup terraform
```

## Use the plugin

| Task | Skill |
| --- | --- |
| Discover provider versions and author configuration | `terraform-author` |
| Validate behavior with the testing framework | `terraform-test` |
| Diagnose errors and provider behavior | `terraform-troubleshoot` |

Author HashiCorp Configuration Language (HCL) with explicit provider constraints,
typed variables, useful outputs, and reusable modules. Look up current Registry
versions before selecting constraints. Mark confidential values as sensitive
and keep provider credentials outside configuration.

Ask for authoring, testing, or troubleshooting in ordinary language. The plugin
provides these skills and CLI readiness; it has no plugin-specific slash command.

## Verify

Run `terraform fmt -check` and `terraform validate` in the project directory.
Run relevant `terraform test` cases, then inspect a plan against the intended
account and workspace before any apply.

## Clean up

Destroy only resources you created for testing, using a reviewed plan. Keep
state in its protected backend and remove disposable local plan files.

For plugin removal, follow
[Remove a plugin](/marketplace/en/getting-started/#remove-a-plugin).
