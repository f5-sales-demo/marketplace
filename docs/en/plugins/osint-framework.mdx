Select open-source intelligence (OSINT) tools and organize authorized investigations.

<Badge text="Security" variant="tip" /> <Badge text="Content" variant="note" />

Plugin identifier: `osint-framework`. [Source and release metadata](https://github.com/f5-sales-demo/marketplace/tree/main/plugins/osint-framework/.xcsh-plugin/plugin.json).

## Prerequisites

Follow [Get started](/marketplace/en/getting-started/) for shared installation
requirements. Allow about 5 minutes for an initial check after setup.

- A defined investigation scope and permission for the target.
- Network access and any command-line tools required by the selected workflow.

## Set up

Install from your shell after registering the marketplace:

```bash
xcsh plugin install osint-framework@f5-sales-demo-marketplace
```

This content plugin has no integration setup or authentication step. Start a
fresh xcsh session to load its skills and commands.

## Use the plugin

Use `/osint-framework:osint-catalog` to browse tool categories,
`/osint-framework:osint-search` to find a tool, and
`/osint-framework:osint-investigate` to coordinate an investigation.

Category skills cover usernames, domains, email, network addresses, social
networks, geolocation, public records, threat intelligence, and other research
areas. `osint-index` routes requests; `opsec` covers operational security.
`osint-researcher`, `osint-investigator`, and `osint-executor` separate tool
selection, correlation, and execution.

## Verify

Check source dates, corroborate key observations, and label inference and
unresolved questions. A catalog entry doesn't prove that a service is available.

## Clean up

Remove temporary collected data according to the engagement's retention
requirements. Keep private investigation evidence out of public artifacts.

For plugin removal, follow
[Remove a plugin](/marketplace/en/getting-started/#remove-a-plugin).
