Select open-source intelligence (OSINT) tools and organize authorized investigations.

<Badge text="Security" variant="tip" /> <Badge text="Content" variant="note" />

## Requirements

- A defined investigation scope and permission for the target.
- Network access and any command-line tools required by the selected workflow.

## Install

```bash
xcsh plugin install osint-framework@f5-sales-demo-marketplace
```

Follow [shared installation and restart instructions](/marketplace/en/getting-started/#install-a-plugin).

## Select tools for an investigation

Define the authorized target, question, and evidence you need. Use `/osint-framework:osint-catalog` to choose a category and `/osint-framework:osint-search` to find a tool. Run `/osint-framework:osint-investigate` for the scoped investigation and corroborate key findings.

Use `/osint-framework:osint-catalog` to browse tool categories,
`/osint-framework:osint-search` to find a tool, and
`/osint-framework:osint-investigate` to coordinate an investigation.

The catalog covers usernames, domains, email, network addresses, social networks, geolocation, public records, and threat intelligence. Check each service’s availability and access requirements before using it.

## Check the result

Check source dates, corroborate key observations, and label inference and
unresolved questions. A catalog entry doesn't prove that a service is available.
