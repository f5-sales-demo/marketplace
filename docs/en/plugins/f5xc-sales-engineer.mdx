Prepare, execute, and present F5 Distributed Cloud demos with evidence for each result.

<Badge text="Sales" variant="tip" /> <Badge text="Content" variant="note" />

## Requirements

- An authorized demo environment.
- Product guidance in `DEMO_PRODUCT_EXPERTISE.md`.
- Demo procedures in `docs/demo/index.mdx` and its phase pages.

## Install

```bash
xcsh plugin install sales-engineer@f5-sales-demo-marketplace
```

Follow [shared installation and restart instructions](/marketplace/en/getting-started/#install-a-plugin).

## Prepare the documented demo

Open the demo repository and ask: “Read `DEMO_PRODUCT_EXPERTISE.md` and `docs/demo/index.mdx`, check readiness, and prepare the documented demo.” Follow its build, attack, and mitigation procedures; explain each result using the recorded evidence.

Use the demo repository’s procedures to select exact commands and resource names. Check its readiness gates before each phase and cite product guidance when explaining the results.

## Check the result

Check each phase against its documented evidence gates. Record the deployed
behavior, mitigation result, and unresolved questions in the debrief.

## Finish the task

Follow the demo repository's teardown procedure. Confirm that owned resources
are removed and billing has stopped before ending the session.
