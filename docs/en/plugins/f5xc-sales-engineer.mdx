Plugin identifier: `sales-engineer`. [Source and release metadata](https://github.com/f5-sales-demo/marketplace/tree/main/plugins/sales-engineer/.xcsh-plugin/plugin.json).

## Prerequisites

Follow [Get started](/marketplace/en/getting-started/) for shared installation
requirements. Allow about 5 minutes for an initial check after setup.

- An authorized demo environment.
- Product guidance in `DEMO_PRODUCT_EXPERTISE.md`.
- Demo procedures in `docs/demo/index.mdx` and its phase pages.

## Set up

Install from your shell after registering the marketplace:

```bash
xcsh plugin install sales-engineer@f5-sales-demo-marketplace
```

This content plugin has no integration setup or authentication step. Start a
fresh xcsh session to load its skills and commands.

## Use the plugin

Ask to prepare or run a demo. The `persona` skill routes the request;
`demo-ops` checks the environment, `demo-executor` follows the documented
build, attack, and mitigation phases, and `presenter` explains the result.
The `subject-matter-expert` skill answers questions from cited product material.

`demo-researcher` gathers references. `demo-housekeeping` checks readiness and
teardown. Use the demo repository's procedures to select exact commands and
resource names.

## Verify

Check each phase against its documented evidence gates. Record the deployed
behavior, mitigation result, and unresolved questions in the debrief.

## Clean up

Follow the demo repository's teardown procedure. Confirm that owned resources
are removed and billing has stopped before ending the session.

For plugin removal, follow
[Remove a plugin](/marketplace/en/getting-started/#remove-a-plugin).
