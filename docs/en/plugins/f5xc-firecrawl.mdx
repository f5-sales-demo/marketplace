Scrape pages, crawl sites, and extract content through a local Firecrawl service.

<Badge text="Documentation and web" variant="tip" /> <Badge text="Integrated" variant="note" />

## Requirements

- A reachable local Firecrawl service, normally `http://127.0.0.1:3002/`.
- `curl` and `jq` for the operator workflows.
- Optional service backends for search or structured extraction.

## Install

```bash
xcsh plugin install firecrawl@f5-sales-demo-marketplace
```

Complete [integration setup](/marketplace/en/getting-started/#complete-setup) for the local service. Basic scraping needs no language model; search and structured extraction depend on optional service backends.

## Scrape one page

Run `/firecrawl:scrape https://example.com` inside xcsh. Inspect the returned content and source URL before expanding to a crawl. Supply a page limit when requesting multiple pages.

| Task | Command |
| --- | --- |
| Scrape one page | `/firecrawl:scrape` |
| Scrape several pages | `/firecrawl:batch-scrape` |
| Crawl or map a site | `/firecrawl:crawl`, `/firecrawl:map` |
| Search or research a topic | `/firecrawl:search`, `/firecrawl:research` |
| Extract structured content | `/firecrawl:extract` |
| Create an `llms.txt` summary | `/firecrawl:llmstxt` |

Provide the target and a bounded page limit for a crawl. Local hosting doesn't
supply search or extraction backends; check service configuration before using
those operations.

## Check the result

Run `/firecrawl:firecrawl-status`. Check a scrape for the requested content
and source URL. For asynchronous jobs, confirm completion and inspect errors.
