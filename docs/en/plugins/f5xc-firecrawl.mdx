Scrape pages, crawl sites, and extract content through a local Firecrawl service.

<Badge text="Productivity" variant="tip" /> <Badge text="Integrated" variant="note" />

Plugin identifier: `firecrawl`. [Source and release metadata](https://github.com/f5-sales-demo/marketplace/tree/main/plugins/firecrawl/.xcsh-plugin/plugin.json).

## Prerequisites

Follow [Get started](/marketplace/en/getting-started/) for shared installation
requirements. Allow about 5 minutes for an initial check after setup.

- A reachable local Firecrawl service, normally `http://127.0.0.1:3002/`.
- `curl` and `jq` for the operator workflows.
- A configured language model backend for operations that require one.

## Set up

Install from your shell after registering the marketplace:

```bash
xcsh plugin install firecrawl@f5-sales-demo-marketplace
```

Check readiness. If setup is required, run the human setup flow in an
interactive terminal:

```bash
xcsh plugin status firecrawl
xcsh plugin setup firecrawl
```

## Use the plugin

| Task | Command |
| --- | --- |
| Scrape one page | `/firecrawl:scrape` |
| Scrape several pages | `/firecrawl:batch-scrape` |
| Crawl or map a site | `/firecrawl:crawl`, `/firecrawl:map` |
| Search or research a topic | `/firecrawl:search`, `/firecrawl:research` |
| Extract structured content | `/firecrawl:extract` |
| Create an `llms.txt` summary | `/firecrawl:llmstxt` |

`web-scraper` routes work to `firecrawl-operator` or `firecrawl-researcher`.
Provide the target and a bounded page limit for a crawl. Local hosting doesn't
supply search or extraction backends; check service configuration before using
those operations.

## Verify

Run `/firecrawl:firecrawl-status`. Check a scrape for the requested content
and source URL. For asynchronous jobs, confirm completion and inspect errors.

## Clean up

Cancel running crawl jobs through the service before deleting disposable
results. Stop a local service only if you started it for this task.

For plugin removal, follow
[Remove a plugin](/marketplace/en/getting-started/#remove-a-plugin).
