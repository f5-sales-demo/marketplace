---
title: Development container plugin retired
description: The deprecated Devcontainer plugin has been removed from the marketplace.
---

The `devcontainer` plugin is deprecated and has been removed from the marketplace.
It is no longer available for installation. Existing installations are retained;
remove them through xcsh plugin management when they are no longer needed.

Historical releases and qualification receipts remain available. The plugin's
presentation tasks are preserved in the [retired surfaces tracker](https://github.com/f5-sales-demo/marketplace/blob/main/docs/marketplace-presentation-todo.md#retired-surfaces).

Removal is tracked in [#1707](https://github.com/f5-sales-demo/marketplace/issues/1707).
