<Badge text="Development" variant="tip" /> <Badge text="Integrated" variant="note" />

## Requirements

- A supported development container runtime.
- Access to the container's tool catalog and Dockerfile.

## Install

```bash
xcsh plugin install devcontainer@f5-sales-demo-marketplace
```

Follow [shared installation and restart instructions](/marketplace/en/getting-started/#install-a-plugin).

## Inspect tools and catalog drift

Run `/devcontainer:devcontainer-status` in the intended container. Ask which installed tool fits your task and compare its version and authentication requirements with the catalog. For drift, compare the catalog with the Dockerfile.

Use `tool-catalog` to choose a tool and find its usage and authentication
requirements. Use `self-awareness` to inspect the container's identity, build
history, resources, and health.

For tool changes, update the container build source and rebuild so the result persists.

## Check the result

Run `/devcontainer:devcontainer-status` in the intended container. Compare
tool versions with the catalog and record any missing or unexpected tools.
