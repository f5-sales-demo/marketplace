Plugin identifier: `devcontainer`. [Source and release metadata](https://github.com/f5-sales-demo/marketplace/tree/main/plugins/devcontainer/.xcsh-plugin/plugin.json).

## Prerequisites

Follow [Get started](/marketplace/en/getting-started/) for shared installation
requirements. Allow about 5 minutes for an initial check after setup.

- A supported development container runtime.
- Access to the container's tool catalog and Dockerfile.

## Set up

Install from your shell after registering the marketplace:

```bash
xcsh plugin install devcontainer@f5-sales-demo-marketplace
```

The integration detects the running container; it has no setup procedure.

## Use the plugin

Use `tool-catalog` to choose a tool and find its usage and authentication
requirements. Use `self-awareness` to inspect the container's identity, build
history, resources, and health.

`tool-advisor` recommends tools. `tool-auditor` compares the catalog with the
Dockerfile. `container-introspector` gathers live identity and health evidence.
`container-maintainer` handles requested tool changes and persistence work.

## Verify

Run `/devcontainer:devcontainer-status` in the intended container. Compare
tool versions with the catalog and record any missing or unexpected tools.

## Clean up

Remove temporary diagnostic output. Persist intended tool changes through
the container build source before discarding the container.

For plugin removal, follow
[Remove a plugin](/marketplace/en/getting-started/#remove-a-plugin).
