Observe and control an Ubuntu Xorg desktop through structured xorgctl operations.

<Badge text="Desktop" variant="tip" /> <Badge text="Integrated" variant="note" />

## Requirements

- Ubuntu 24.04 with passwordless `sudo` for reviewed setup.
- A supported Xorg desktop and access to the intended display.

## Install

```bash
xcsh plugin install xorg@f5-sales-demo-marketplace
```

Check readiness and complete [integration setup](/marketplace/en/getting-started/#complete-setup) if required.

## Observe and verify a desktop action

Ask `xorg_desktop` to inspect the intended Xorg session and its live windows. Select the window, request one bounded action, and observe the resulting window or accessibility state. Repeat observation before the next action.

The `xorg-display` skill and `xorg_desktop` tool use the public
`xorgctl --json` interface. Follow observe, resolve, act, and verify when
interacting with applications. Resolve live application and window identifiers
before input, use bounded input leases, and inspect structured failures.

Setup provisions the desktop automation substrate. Application launch, window
control, accessibility observation, virtual devices, and isolated console
operations use the generic desktop interface. Select the intended session
explicitly when several desktops exist.

## Check the result

Check integration status and inspect the selected desktop. Verify the
resulting window or accessibility state after each action; input submission
alone doesn't establish completion.

## Finish the task

Release task-owned input leases and stop isolated desktops or workers you
created. Leave unrelated applications and existing display sessions running.
