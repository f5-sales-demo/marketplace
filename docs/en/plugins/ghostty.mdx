Set up a Linux Ghostty terminal for Xorg desktops and Herdr sessions.

<Badge text="Development" variant="tip" /> <Badge text="Integrated" variant="note" />

Plugin identifier: `ghostty`. [Source and release metadata](https://github.com/f5-sales-demo/marketplace/tree/main/plugins/ghostty/.xcsh-plugin/plugin.json).

## Prerequisites

Follow [Get started](/marketplace/en/getting-started/) for shared installation
requirements. Allow about 5 minutes for an initial check after setup.

- Ubuntu Linux.
- The Xorg and Herdr plugins.
- Access to the intended desktop and user configuration.

Plugin dependencies: [Xorg](/marketplace/en/plugins/xorg/), [Herdr](/marketplace/en/plugins/herdr/).

## Set up

Install from your shell after registering the marketplace:

```bash
xcsh plugin install ghostty@f5-sales-demo-marketplace
```

Check readiness. If setup is required, run the human setup flow in an
interactive terminal:

```bash
xcsh plugin status ghostty
xcsh plugin setup ghostty
```

A reviewed direct install can authorize bounded setup. Dependency installation
and upgrades don't grant that setup authorization.

## Use the plugin

This plugin installs and configures Ghostty. It has no Ghostty-specific
runtime tool and doesn't launch a terminal during setup.

Use the generic Xorg application interface to launch Ghostty in the selected
desktop. The underlying application command is:

```bash
ghostty -e herdr
```

Inspect the live window before maximizing or entering fullscreen. The user's
Ghostty configuration, including any `XORGCTL` block, remains authoritative.
For image workflows, verify visible Kitty graphics rendering through the
actual terminal and Herdr pane.

## Verify

Check integration status, launch a task-owned terminal, and confirm its
rendered output. A successful process or graphics acknowledgement alone
doesn't establish visible image rendering.

## Clean up

Close the terminal you created for the task. Keep the user's configuration,
existing Herdr sessions, and unrelated windows intact.

For plugin removal, follow
[Remove a plugin](/marketplace/en/getting-started/#remove-a-plugin).
