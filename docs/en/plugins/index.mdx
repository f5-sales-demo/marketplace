[marketplace manifest](https://github.com/f5-sales-demo/marketplace/blob/main/.xcsh-plugin/marketplace.json).
Use the identifier column when installing; the manifest records current versions.

## Choose a lifecycle

| Lifecycle | What happens after installation |
| --- | --- |
| Content | Skills, commands, and reference material load without integration setup. |
| On demand | Live evidence is collected only when requested; network access may be required. |
| Integrated | xcsh checks runtime readiness. Follow the page's setup and dependency requirements. |

Each plugin page explains prerequisites, setup, tasks, verification, and cleanup.
Follow [Get started](/marketplace/en/getting-started/) to register the marketplace
and install your first plugin.
