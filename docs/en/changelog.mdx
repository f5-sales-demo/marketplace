Use [GitHub releases](https://github.com/f5-sales-demo/marketplace/releases) for
plugin release notes and downloadable artifacts. Check the notes for your
plugin before upgrading, especially when it manages saved plans or receipts.

The [repository changelog](https://github.com/f5-sales-demo/marketplace/blob/main/CHANGELOG.md)
records release history. The [commit history](https://github.com/f5-sales-demo/marketplace/commits/main/)
shows documentation and source changes between releases.

Return to the [plugin catalog](/marketplace/en/plugins/) for current workflows,
or follow [upgrade instructions](/marketplace/en/getting-started/#update-a-plugin).
