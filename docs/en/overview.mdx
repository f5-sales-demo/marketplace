The F5 sales-demo marketplace extends xcsh with documentation, sales, cloud,
development, security, and desktop workflows. Its 23 plugins package skills,
commands, reference material, and, where needed, native tools and integrations.

## Choose a plugin

Browse the [complete catalog](/marketplace/en/plugins/) by task and identifier.
Each page explains requirements, setup, supported tasks, verification, and cleanup.
The [marketplace manifest](https://github.com/f5-sales-demo/marketplace/blob/main/.xcsh-plugin/marketplace.json)
records current versions and plugin dependencies.

## Understand the lifecycle

| Mode | Use it for | Readiness |
| --- | --- | --- |
| Content | Guidance, reviews, and reference workflows | Loads without integration setup. |
| On demand | Live status and network evidence | Requires access to sources when invoked. |
| Integrated | Cloud accounts, installed tools, and desktop services | Probes runtime requirements and reports setup needs. |

Installing plugin files and configuring an integration are separate stages.
Some reviewed direct installs include bounded setup authorization. An upgrade
or dependency install doesn't grant that same authorization. Human setup shows
its installation, authentication, environment, collection, and verification plan.

## Start a workflow

1. Register the marketplace using [Get started](/marketplace/en/getting-started/).
2. Install the plugin for your task.
3. Complete its setup if required.
4. Start a fresh xcsh session to load installed changes.
5. Ask for a task or invoke a documented command.

Skills guide the assistant when a task matches their scope. Commands provide
explicit entry points. Agents handle specialized work; native tools implement
typed operations. Integrations report whether their account or runtime is ready.

This repository uses the xcsh manifest layout. OpenAI and Claude-compatible
plugin hosts have their own packaging contracts; check host compatibility
before reusing an xcsh package in another client.
