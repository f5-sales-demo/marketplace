The F5 sales-demo marketplace extends xcsh with 23 plugins for documentation,
sales, cloud, security, development, and desktop work. Install the plugin for
your task to add relevant guidance, commands, and, where needed, native tools.

## Choose a workflow

- **Documentation and web:** review MDX pages and brand assets, preview documentation, or scrape web content.
- **Sales:** prepare documented demos, qualify deals with MEDDPICC, or query Salesforce pipeline evidence.
- **Cloud:** inspect accounts and incidents, configure F5 Distributed Cloud, or plan Customer Edge deployments.
- **Security:** convert ASM policies or choose tools for a scoped investigation.
- **Development:** inspect GitHub or GitLab work, validate Terraform, or explore container tools.
- **Desktop:** observe Xorg applications, work with Herdr and Ghostty, or join Zoom meetings.

The [plugin catalog](/marketplace/en/plugins/) lists every plugin by task and
identifier. Each article gives you its requirements, installation command, a
first task, expected results, and relevant next steps.

## Prepare xcsh

Use [Get started](/marketplace/en/getting-started/) to check the built-in
marketplace, install a plugin, and complete any account or desktop setup.
Content plugins load guidance without integration setup; live cloud and desktop
work also needs the account or runtime described in its article.

For new plugins or documentation changes, use the
[contributor guide](/marketplace/en/contributing/) and
[packaging reference](/marketplace/en/reference/).
