يقودك هذا الدليل خلال إضافة سوق f5-sales-demo
إلى Claude Code وتثبيت أول ملحق لك.

## المتطلبات الأساسية

- Claude Code **v1.0.33** أو أحدث (دعم سوق الملحقات)
- حساب GitHub مع إمكانية الوصول إلى مؤسسة
  [f5-sales-demo](https://github.com/f5-sales-demo)

## التثبيت

<Steps>

1. **إضافة السوق**

   في أي جلسة Claude Code، قم بتشغيل:

   ```text
   /plugin marketplace add f5-sales-demo/marketplace
   ```

   يقوم هذا بتسجيل السوق كمصدر للملحقات. تحتاج فقط إلى القيام بذلك مرة واحدة.

2. **تصفح الملحقات المتاحة**

   اعرض ما يقدمه السوق:

   ```text
   /plugin marketplace list f5-sales-demo-marketplace
   ```

3. **تثبيت ملحق**

   قم بتثبيت الملحق الذي تحتاجه:

   ```text
   /plugin install f5xc-docs-tools@f5-sales-demo-marketplace
   /plugin install f5xc-sales-engineer@f5-sales-demo-marketplace
   ```

4. **استخدام الملحق**

   انتقل إلى أي مستودع محتوى f5-sales-demo.

   بالنسبة لـ **أدوات التوثيق**، قم بتشغيل أمر مراجعة MDX:

   ```text
   /f5xc-docs-tools:review-mdx
   ```

   بالنسبة لـ **sales engineer**، استخدم عبارات التشغيل مثل
   "prepare the demo" أو "run the demo" أو "walk through the demo" — ينشط الملحق تلقائيًا.

</Steps>

## تحديث الملحقات

لتحديث ملحق مثبت إلى أحدث إصدار:

```text
/plugin update f5xc-docs-tools@f5-sales-demo-marketplace
/plugin update f5xc-sales-engineer@f5-sales-demo-marketplace
```

## إلغاء التثبيت

إزالة ملحق:

```text
/plugin uninstall f5xc-docs-tools@f5-sales-demo-marketplace
/plugin uninstall f5xc-sales-engineer@f5-sales-demo-marketplace
```

إزالة السوق بالكامل:

```text
/plugin marketplace remove f5-sales-demo-marketplace
```

## تكوين الفريق

لإعداد السوق مسبقًا لفريقك بأكمله، أضفه إلى ملف `.claude/settings.json` الخاص بمشروعك:

```json
{
  "extraKnownMarketplaces": [
    "f5-sales-demo/marketplace"
  ],
  "enabledPlugins": [
    "f5xc-docs-tools@f5-sales-demo-marketplace",
    "f5xc-sales-engineer@f5-sales-demo-marketplace"
  ]
}
```

<Aside type="tip" title="Shared settings">
  يعني تثبيت `.claude/settings.json` في المستودع الخاص بك أن كل عضو في الفريق يحصل على السوق والملحقات تلقائيًا — دون الحاجة إلى إعداد يدوي.
</Aside>

هذا يضمن أن كل مساهم لديه نفس الأدوات المتاحة بدءًا من أول جلسة Claude Code في المستودع.
