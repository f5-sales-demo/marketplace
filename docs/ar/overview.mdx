يعد **سوق ملحقات Claude Code** مجموعة منتقاة من الملحقات التي توسع Claude Code بمهارات وأوامر ووكلاء جدد. تتيح الأسواق للفرق مشاركة الأدوات حتى يحصل كل مطور على نفس الإمكانيات دون الحاجة إلى إعداد يدوي.

يوفر **سوق f5-sales-demo** ملحقات تم بناؤها لمنصة توثيق [f5-sales-demo](https://github.com/f5-sales-demo) — وهي منظومة تضم أكثر من 20 مستودعًا تنشر مواقع Astro/Starlight على GitHub Pages باستخدام خط تجميع مشترك.

## كيفية العمل

1. **إضافة السوق** إلى Claude Code — يسجل هذا السوق كمصدر للملحقات
2. **تثبيت الملحقات** من السوق — يضيف كل ملحق مهارات وأوامر إلى جلسة Claude Code الخاصة بك
3. **استخدام الأدوات** — تنشط الملحقات تلقائيًا بناءً على السياق، أو يمكنك استدعاء أوامرها مباشرة

## الملحقات المتاحة

| الملحق | الفئة | الوصف |
| --- | --- | --- |
| [f5xc-docs-tools](/marketplace/en/plugins/f5xc-docs-tools/) | الإنتاجية | أدوات التحقق من صحة محتوى MDX ومراجعته لمستودعات التوثيق |
| [f5xc-sales-engineer](/marketplace/en/plugins/f5xc-sales-engineer/) | الإنتاجية | إطار عمل شخصية Sales Engineer — تنفيذ العروض التوضيحية، والتقديم، والأسئلة والأجوبة، وإدارة البيئة |

## البدء السريع

أضف السوق وقم بتثبيت ملحق أدوات التوثيق:

```text
/plugin marketplace add f5-sales-demo/marketplace
/plugin install f5xc-docs-tools@f5-sales-demo-marketplace
```

انظر [البدء](/marketplace/en/getting-started/) للحصول على شرح كامل.

## البنية الهيكلية

السوق عبارة عن مستودع Git يحتوي على ملحق واحد أو أكثر. يغلف كل ملحق المهارات والأوامر والوكلاء في وحدة واحدة قابلة للتثبيت.

```text
Marketplace (marketplace.json)
└── Plugin (plugin.json)
    ├── Skills (SKILL.md)
    │   └── References (data files)
    ├── Commands (.md)
    └── Agents (.md)
```

- **Marketplace** — السجل. يعرض الملحقات المتاحة مع البيانات الوصفية للاكتشاف والتثبيت.
- **Plugin** — الوحدة القابلة للتثبيت. تحتوي على مهارة واحدة أو أكثر، أو أوامر، أو وكلاء.
- **Skill** — المعرفة السياقية التي ينشطها Claude تلقائيًا بناءً على المهمة القائمة.
- **Command** — أمر slash يستدعيه المستخدم مباشرة (على سبيل المثال، `/review-mdx`).
- **Agent** — وكيل فرعي متخصص يتعامل مع المهام المعقدة متعددة الخطوات بشكل مستقل.
