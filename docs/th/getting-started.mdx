คู่มือนี้จะแนะนำคุณเกี่ยวกับการเพิ่มมาร์เก็ตเพลส f5-sales-demo
ไปยัง Claude Code และติดตั้งปลั๊กอินแรกของคุณ

## ข้อกำหนดเบื้องต้น

- Claude Code **v1.0.33** หรือใหม่กว่า (รองรับปลั๊กอินมาร์เก็ตเพลส)
- บัญชี GitHub ที่มีสิทธิ์เข้าถึงองค์กร
  [f5-sales-demo](https://github.com/f5-sales-demo)

## การติดตั้ง

<Steps>

1. **เพิ่มมาร์เก็ตเพลส**

   ในเซสชัน Claude Code ใดก็ได้ ให้รัน:

   ```text
   /plugin marketplace add f5-sales-demo/marketplace
   ```

   คำสั่งนี้จะลงทะเบียนมาร์เก็ตเพลสเป็นแหล่งที่มาของปลั๊กอิน คุณต้องทำคำสั่งนี้
   เพียงครั้งเดียวเท่านั้น

2. **เรียกดูปลั๊กอินที่มีอยู่**

   แสดงรายการสิ่งที่มาร์เก็ตเพลสมีให้:

   ```text
   /plugin marketplace list f5-sales-demo-marketplace
   ```

3. **ติดตั้งปลั๊กอิน**

   ติดตั้งปลั๊กอินที่คุณต้องการ:

   ```text
   /plugin install f5xc-docs-tools@f5-sales-demo-marketplace
   /plugin install f5xc-sales-engineer@f5-sales-demo-marketplace
   ```

4. **ใช้งานปลั๊กอิน**

   ไปยังคลังเก็บเนื้อหา f5-sales-demo ใดก็ได้

   สำหรับ **เครื่องมือเอกสาร** ให้รันคำสั่งตรวจสอบ MDX:

   ```text
   /f5xc-docs-tools:review-mdx
   ```

   สำหรับ **sales engineer** ให้ใช้วลีเปิดใช้งาน เช่น
   "prepare the demo", "run the demo" หรือ "walk through
   the demo" — ปลั๊กอินจะทำงานโดยอัตโนมัติ

</Steps>

## การอัปเดตปลั๊กอิน

หากต้องการอัปเดตปลั๊กอินที่ติดตั้งให้เป็นเวอร์ชันล่าสุด:

```text
/plugin update f5xc-docs-tools@f5-sales-demo-marketplace
/plugin update f5xc-sales-engineer@f5-sales-demo-marketplace
```

## การถอนการติดตั้ง

ลบปลั๊กอิน:

```text
/plugin uninstall f5xc-docs-tools@f5-sales-demo-marketplace
/plugin uninstall f5xc-sales-engineer@f5-sales-demo-marketplace
```

ลบมาร์เก็ตเพลสออกทั้งหมด:

```text
/plugin marketplace remove f5-sales-demo-marketplace
```

## การกำหนดค่าทีม

หากต้องการกำหนดค่ามาร์เก็ตเพลสล่วงหน้าสำหรับทั้งทีมของคุณ ให้เพิ่มลงใน
`.claude/settings.json` ของโปรเจกต์คุณ:

```json
{
  "extraKnownMarketplaces": [
    "f5-sales-demo/marketplace"
  ],
  "enabledPlugins": [
    "f5xc-docs-tools@f5-sales-demo-marketplace",
    "f5xc-sales-engineer@f5-sales-demo-marketplace"
  ]
}
```

<Aside type="tip" title="Shared settings">
  การคอมมิต `.claude/settings.json` ไปยังคลังเก็บของคุณหมายความว่า
  สมาชิกทุกคนในทีมจะได้รับมาร์เก็ตเพลสและปลั๊กอิน
  โดยอัตโนมัติ — ไม่จำเป็นต้องตั้งค่าด้วยตนเอง
</Aside>

สิ่งนี้ทำให้มั่นใจได้ว่าผู้ร่วมสมทบทุกคนมีเครื่องมือเดียวกันพร้อมใช้งาน
ตั้งแต่วันแรกในเซสชัน Claude Code ในคลังเก็บนี้
