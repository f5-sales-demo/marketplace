**มาร์เก็ตเพลสปลั๊กอิน Claude Code** คือคอลเลกชันปลั๊กอินที่ได้รับการคัดสรร
ซึ่งช่วยขยายความสามารถของ Claude Code ด้วยทักษะ คำสั่ง และ
เอเจนต์ใหม่ๆ มาร์เก็ตเพลสช่วยให้ทีมแบ่งปันเครื่องมือเพื่อให้นักพัฒนาทุกคน
ได้รับความสามารถเดียวกันโดยไม่ต้องตั้งค่าด้วยตนเอง

**f5-sales-demo มาร์เก็ตเพลส** มีปลั๊กอินที่สร้างขึ้นสำหรับ
แพลตฟอร์มเอกสาร [f5-sales-demo](https://github.com/f5-sales-demo)
— ระบบนิเวศที่ประกอบด้วยคลังเก็บมากกว่า 20 แห่งที่เผยแพร่ไซต์ Astro/Starlight ไปยัง GitHub Pages โดยใช้ไปป์ไลน์การบิลด์ร่วมกัน

## การทำงาน

1. **เพิ่มมาร์เก็ตเพลส** ไปยัง Claude Code — สิ่งนี้จะลงทะเบียนมาร์เก็ตเพลส
   เป็นแหล่งที่มาของปลั๊กอิน
2. **ติดตั้งปลั๊กอิน** จากมาร์เก็ตเพลส — แต่ละปลั๊กอินจะเพิ่ม
   ทักษะและคำสั่งไปยังเซสชัน Claude Code ของคุณ
3. **ใช้เครื่องมือ** — ปลั๊กอินจะทำงานโดยอัตโนมัติตาม
   บริบท หรือคุณสามารถเรียกใช้คำสั่งโดยตรง

## ปลั๊กอินที่มีอยู่

| ปลั๊กอิน | หมวดหมู่ | คำอธิบาย |
| --- | --- | --- |
| [f5xc-docs-tools](/marketplace/en/plugins/f5xc-docs-tools/) | ผลิตภาพ | เครื่องมือตรวจสอบและรีวิวเนื้อหา MDX สำหรับคลังเก็บเอกสาร |
| [f5xc-sales-engineer](/marketplace/en/plugins/f5xc-sales-engineer/) | ผลิตภาพ | กรอบการทำงานของ Sales Engineer — การสาธิต การนำเสนอ Q&A และการจัดการสภาพแวดล้อม |

## เริ่มต้นอย่างรวดเร็ว

เพิ่มมาร์เก็ตเพลสและติดตั้งปลั๊กอินเครื่องมือเอกสาร:

```text
/plugin marketplace add f5-sales-demo/marketplace
/plugin install f5xc-docs-tools@f5-sales-demo-marketplace
```

ดู [เริ่มต้นใช้งาน](/marketplace/en/getting-started/) สำหรับ
คู่มือการใช้งานแบบเต็ม

## สถาปัตยกรรม

มาร์เก็ตเพลสคือคลังเก็บ Git ที่มีปลั๊กอินหนึ่งรายการขึ้นไป
แต่ละปลั๊กอินจะรวมทักษะ คำสั่ง และเอเจนต์เข้าไว้ด้วยกัน
ในยูนิตที่สามารถติดตั้งได้ยูนิตเดียว

```text
Marketplace (marketplace.json)
└── Plugin (plugin.json)
    ├── Skills (SKILL.md)
    │   └── References (data files)
    ├── Commands (.md)
    └── Agents (.md)
```

- **Marketplace** — เรจิสตรี แสดงรายการปลั๊กอินที่มีอยู่
  พร้อมเมทาดาตาสำหรับการค้นพบและการติดตั้ง
- **Plugin** — ยูนิตที่สามารถติดตั้งได้ มีทักษะ คำสั่ง หรือเอเจนต์
  อย่างน้อยหนึ่งรายการ
- **Skill** — ความรู้ตามบริบทที่ Claude จะเรียกใช้โดยอัตโนมัติ
  ตามงานที่กำลังทำอยู่
- **Command** — คำสั่งสแลชที่ผู้ใช้เรียกใช้โดยตรง
  (เช่น `/review-mdx`)
- **Agent** — ซับเอเจนต์เฉพาะทางที่จัดการงานที่ซับซ้อน
  และมีหลายขั้นตอนโดยอัตโนมัติ
