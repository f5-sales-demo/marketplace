Questa guida ti accompagna nell'aggiunta del marketplace f5-sales-demo
a Claude Code e nell'installazione del tuo primo plugin.

## Prerequisiti

- Claude Code **v1.0.33** o successivo (supporto per il marketplace dei plugin)
- Un account GitHub con accesso all'organizzazione
  [f5-sales-demo](https://github.com/f5-sales-demo)

## Installazione

<Steps>

1. **Aggiungi il marketplace**

   In qualsiasi sessione di Claude Code, esegui:

   ```text
   /plugin marketplace add f5-sales-demo/marketplace
   ```

   Questo registra il marketplace come sorgente di plugin. Devi
   farlo solo una volta.

2. **Esplora i plugin disponibili**

   Elenca ciò che offre il marketplace:

   ```text
   /plugin marketplace list f5-sales-demo-marketplace
   ```

3. **Installa un plugin**

   Installa il plugin di cui hai bisogno:

   ```text
   /plugin install f5xc-docs-tools@f5-sales-demo-marketplace
   /plugin install f5xc-sales-engineer@f5-sales-demo-marketplace
   ```

4. **Usa il plugin**

   Naviga in un qualsiasi repository di contenuti f5-sales-demo.

   Per gli **strumenti di documentazione**, esegui il comando di revisione MDX:

   ```text
   /f5xc-docs-tools:review-mdx
   ```

   Per **sales engineer**, usa frasi di attivazione come
   "prepare the demo", "run the demo" o "walk through
   the demo" — il plugin si attiva automaticamente.

</Steps>

## Aggiornamento dei plugin

Per aggiornare un plugin installato all'ultima versione:

```text
/plugin update f5xc-docs-tools@f5-sales-demo-marketplace
/plugin update f5xc-sales-engineer@f5-sales-demo-marketplace
```

## Disinstallazione

Rimuovi un plugin:

```text
/plugin uninstall f5xc-docs-tools@f5-sales-demo-marketplace
/plugin uninstall f5xc-sales-engineer@f5-sales-demo-marketplace
```

Rimuovi completamente il marketplace:

```text
/plugin marketplace remove f5-sales-demo-marketplace
```

## Configurazione del team

Per preconfigurare il marketplace per l'intero team, aggiungilo
al file `.claude/settings.json` del tuo progetto:

```json
{
  "extraKnownMarketplaces": [
    "f5-sales-demo/marketplace"
  ],
  "enabledPlugins": [
    "f5xc-docs-tools@f5-sales-demo-marketplace",
    "f5xc-sales-engineer@f5-sales-demo-marketplace"
  ]
}
```

<Aside type="tip" title="Shared settings">
  Inviare `.claude/settings.json` al repository significa che
  ogni membro del team ottiene automaticamente il marketplace e i plugin
  — senza alcuna configurazione manuale richiesta.
</Aside>

Questo garantisce che ogni collaboratore disponga degli stessi strumenti
fin dalla sua prima sessione Claude Code nel repository.
