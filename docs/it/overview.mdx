Un **marketplace di plugin di Claude Code** è una raccolta selezionata di
plugin che estendono Claude Code con nuove competenze, comandi e
agenti. I marketplace consentono ai team di condividere gli strumenti in modo che ogni sviluppatore
ottenga le stesse funzionalità senza configurazione manuale.

Il **Marketplace f5-sales-demo** fornisce plugin realizzati per
la piattaforma di documentazione [f5-sales-demo](https://github.com/f5-sales-demo)
— un ecosistema di oltre 20 repository che pubblicano siti Astro/Starlight su GitHub Pages utilizzando una pipeline di build condivisa.

## Come funziona

1. **Aggiungi il marketplace** a Claude Code — questo lo registra
   come sorgente di plugin
2. **Installa i plugin** dal marketplace — ogni plugin aggiunge
   competenze e comandi alla tua sessione Claude Code
3. **Usa gli strumenti** — i plugin si attivano automaticamente in base al
   contesto, oppure puoi invocare direttamente i loro comandi

## Plugin disponibili

| Plugin | Categoria | Descrizione |
| --- | --- | --- |
| [f5xc-docs-tools](/marketplace/en/plugins/f5xc-docs-tools/) | Produttività | Strumenti di convalida e revisione dei contenuti MDX per repository di documentazione |
| [f5xc-sales-engineer](/marketplace/en/plugins/f5xc-sales-engineer/) | Produttività | Framework per persona Sales Engineer — esecuzione demo, presentazione, Q&A, gestione dell'ambiente |

## Avvio rapido

Aggiungi il marketplace e installa il plugin degli strumenti di documentazione:

```text
/plugin marketplace add f5-sales-demo/marketplace
/plugin install f5xc-docs-tools@f5-sales-demo-marketplace
```

Vedi [Guida introduttiva](/marketplace/en/getting-started/) per una
procedura dettagliata completa.

## Architettura

Un marketplace è un repository Git che contiene uno o più
plugin. Ogni plugin racchiude competenze, comandi e agenti
in un'unica unità installabile.

```text
Marketplace (marketplace.json)
└── Plugin (plugin.json)
    ├── Skills (SKILL.md)
    │   └── References (data files)
    ├── Commands (.md)
    └── Agents (.md)
```

- **Marketplace** — il registro. Elenca i plugin disponibili
  con i metadati per l'individuazione e l'installazione.
- **Plugin** — l'unità installabile. Contiene una o più
  competenze, comandi o agenti.
- **Skill** — conoscenza contestuale che Claude attiva
  automaticamente in base al compito da svolgere.
- **Command** — un comando slash invocato direttamente dall'utente
  (ad es. `/review-mdx`).
- **Agent** — un sotto-agente specializzato che gestisce in modo autonomo
  compiti complessi e articolati in più passaggi.
