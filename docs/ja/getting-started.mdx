このガイドでは、Claude Code に f5-sales-demo
マーケットプレイスを追加し、最初のプラグインをインストールする手順を説明します。

## 前提条件

- Claude Code **v1.0.33** 以降（プラグインマーケットプレイスのサポート）
- [f5-sales-demo](https://github.com/f5-sales-demo)
  組織へのアクセス権を持つ GitHub アカウント

## インストール

<Steps>

1. **マーケットプレイスの追加**

   Claude Code セッションで次を実行します：

   ```text
   /plugin marketplace add f5-sales-demo/marketplace
   ```

   これにより、マーケットプレイスがプラグインソースとして登録されます。この操作は
   1 回のみ必要です。

2. **利用可能なプラグインの閲覧**

   マーケットプレイスが提供する一覧を表示します：

   ```text
   /plugin marketplace list f5-sales-demo-marketplace
   ```

3. **プラグインのインストール**

   必要なプラグインをインストールします：

   ```text
   /plugin install f5xc-docs-tools@f5-sales-demo-marketplace
   /plugin install f5xc-sales-engineer@f5-sales-demo-marketplace
   ```

4. **プラグインの使用**

   任意の f5-sales-demo コンテンツリポジトリに移動します。

   **ドキュメントツール**の場合は、MDX レビューコマンドを実行します：

   ```text
   /f5xc-docs-tools:review-mdx
   ```

   **セールスエンジニア**の場合は、「prepare the demo」、「run the demo」、または
   「walk through the demo」などのトリガーフレーズを使用します — プラグインが自動的に起動します。

</Steps>

## プラグインの更新

インストールされているプラグインを最新バージョンに更新するには：

```text
/plugin update f5xc-docs-tools@f5-sales-demo-marketplace
/plugin update f5xc-sales-engineer@f5-sales-demo-marketplace
```

## アンインストール

プラグインの削除：

```text
/plugin uninstall f5xc-docs-tools@f5-sales-demo-marketplace
/plugin uninstall f5xc-sales-engineer@f5-sales-demo-marketplace
```

マーケットプレイス全体の削除：

```text
/plugin marketplace remove f5-sales-demo-marketplace
```

## チーム設定

チーム全体でマーケットプレイスを事前設定するには、プロジェクトの
`.claude/settings.json` に追加します：

```json
{
  "extraKnownMarketplaces": [
    "f5-sales-demo/marketplace"
  ],
  "enabledPlugins": [
    "f5xc-docs-tools@f5-sales-demo-marketplace",
    "f5xc-sales-engineer@f5-sales-demo-marketplace"
  ]
}
```

<Aside type="tip" title="Shared settings">
  `.claude/settings.json` をリポジトリにコミットすることで、
  チームメンバー全員が手動設定なしで自動的に
  マーケットプレイスとプラグインを利用できるようになります。
</Aside>

これにより、すべてのコントリビューターがリポジトリでの最初の Claude Code セッションから
同じツールを使用できるようになります。
