**Claude Code プラグインマーケットプレイス**は、Claude Code を新しいスキル、コマンド、
エージェントで拡張するプラグインの厳選されたコレクションです。マーケットプレイスにより、
チームはツールを共有できるため、すべての開発者が手動設定なしで同じ機能を利用できます。

**f5-sales-demo マーケットプレイス**は、[f5-sales-demo](https://github.com/f5-sales-demo)
ドキュメントプラットフォーム用に構築されたプラグインを提供します。これは、共有ビルドパイプラインを使用して
Astro/Starlight サイトを GitHub Pages に公開する 20 以上のリポジトリからなるエコシステムです。

## 仕組み

1. **マーケットプレイスの追加**: Claude Code に追加してプラグインソースとして
   登録します
2. **プラグインのインストール**: マーケットプレイスからインストールします — 各プラグインが
   Claude Code セッションにスキルやコマンドを追加します
3. **ツールの使用**: プラグインはコンテキストに基づいて自動的にアクティブ化されるか、
   コマンドを直接呼び出します

## 利用可能なプラグイン

| プラグイン | カテゴリ | 説明 |
| --- | --- | --- |
| [f5xc-docs-tools](/marketplace/en/plugins/f5xc-docs-tools/) | 生産性 | ドキュメントリポジトリ用の MDX コンテンツ検証およびレビューツール |
| [f5xc-sales-engineer](/marketplace/en/plugins/f5xc-sales-engineer/) | 生産性 | セールスエンジニアペルソナフレームワーク — デモ実行、プレゼンテーション、Q&A、環境管理 |

## クイックスタート

マーケットプレイスを追加し、ドキュメントツールプラグインをインストールします：

```text
/plugin marketplace add f5-sales-demo/marketplace
/plugin install f5xc-docs-tools@f5-sales-demo-marketplace
```

詳細な手順については[はじめに](/marketplace/en/getting-started/)を参照してください。

## アーキテクチャ

マーケットプレイスは、1 つ以上のプラグインを含む Git リポジトリです。
各プラグインは、スキル、コマンド、エージェントを単一のインストール可能なユニットにパッケージ化します。

```text
Marketplace (marketplace.json)
└── Plugin (plugin.json)
    ├── Skills (SKILL.md)
    │   └── References (data files)
    ├── Commands (.md)
    └── Agents (.md)
```

- **Marketplace** — レジストリ。検出とインストールのためのメタデータを含む
  利用可能なプラグインの一覧。
- **Plugin** — インストール可能なユニット。1 つ以上の
  スキル、コマンド、またはエージェントが含まれます。
- **Skill** — 手元のタスクに基づいて Claude が自動的にアクティブ化する
  コンテキスト知識。
- **Command** — ユーザーが直接呼び出すスラッシュコマンド
  （例：`/review-mdx`）。
- **Agent** — 複雑で複数ステップのタスクを自律的に処理する
  専門のサブエージェント。
