Une **place de marché de plugins Claude Code** est une collection sélectionnée
de plugins qui étendent Claude Code avec de nouvelles compétences, commandes et
agents. Les places de marché permettent aux équipes de partager des outils afin que chaque développeur
bénéficie des mêmes capacités sans configuration manuelle.

La **place de marché f5-sales-demo** fournit des plugins conçus pour
la plateforme de documentation [f5-sales-demo](https://github.com/f5-sales-demo)
— un écosystème de plus de 20 dépôts qui publient des sites Astro/Starlight sur GitHub Pages à l'aide d'un pipeline de build partagé.

## Fonctionnement

1. **Ajouter la place de marché** à Claude Code — cela l'enregistre
   en tant que source de plugins
2. **Installer des plugins** depuis la place de marché — chaque plugin ajoute
   des compétences et des commandes à votre session Claude Code
3. **Utiliser les outils** — les plugins s'activent automatiquement en fonction du
   contexte, ou vous pouvez invoquer leurs commandes directement

## Démarrage rapide

Ajouter la place de marché et installer le plugin d'outils de documentation :

```text
/plugin marketplace add f5-sales-demo/marketplace
/plugin install f5xc-docs-tools@f5-sales-demo-marketplace
```

Consultez [Démarrage rapide](/marketplace/en/getting-started/) pour une
présentation complète.

## Architecture

Une place de marché est un dépôt Git qui contient un ou plusieurs
plugins. Chaque plugin regroupe des compétences, des commandes et des agents
dans une seule unité installable.

```text
Marketplace (marketplace.json)
└── Plugin (plugin.json)
    ├── Skills (SKILL.md)
    │   └── References (data files)
    ├── Commands (.md)
    └── Agents (.md)
```

- **Marketplace** — le registre. Liste les plugins disponibles
  avec leurs métadonnées pour la découverte et l'installation.
- **Plugin** — l'unité installable. Contient une ou plusieurs
  compétences, commandes ou agents.
- **Skill** — connaissances contextuelles que Claude active
  automatiquement en fonction de la tâche à accomplir.
- **Command** — une commande slash que l'utilisateur invoque directement
  (par ex. `/review-mdx`).
- **Agent** — un sous-agent spécialisé qui gère de manière autonome
  des tâches complexes et multi-étapes.
