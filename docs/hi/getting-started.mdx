यह गाइड आपको Claude Code में f5-sales-demo
मार्केटप्लेस को जोड़ने और अपना पहला प्लगइन इंस्टॉल करने का तरीका बताती है।

## पूर्वापेक्षित आवश्यकताएं

- Claude Code **v1.0.33** या उसके बाद का संस्करण (प्लगइन मार्केटप्लेस समर्थन)
- [f5-sales-demo](https://github.com/f5-sales-demo)
  संगठन तक पहुंच वाला एक GitHub खाता

## इंस्टॉलेशन

<Steps>

1. **मार्केटप्लेस जोड़ें**

   किसी भी Claude Code सत्र में, चलाएं:

   ```text
   /plugin marketplace add f5-sales-demo/marketplace
   ```

   यह मार्केटप्लेस को प्लगइन स्रोत के रूप में पंजीकृत करता है। आपको यह
   केवल एक बार करने की आवश्यकता है।

2. **उपलब्ध प्लगइन्स ब्राउज़ करें**

   मार्केटप्लेस द्वारा पेश की जाने वाली चीज़ों की सूची देखें:

   ```text
   /plugin marketplace list f5-sales-demo-marketplace
   ```

3. **एक प्लगइन इंस्टॉल करें**

   अपनी आवश्यकता के अनुसार प्लगइन इंस्टॉल करें:

   ```text
   /plugin install f5xc-docs-tools@f5-sales-demo-marketplace
   /plugin install f5xc-sales-engineer@f5-sales-demo-marketplace
   ```

4. **प्लगइन का उपयोग करें**

   किसी भी f5-sales-demo सामग्री रिपॉजिटरी पर जाएं।

   **डॉक्स टूल्स** के लिए, MDX समीक्षा कमांड चलाएं:

   ```text
   /f5xc-docs-tools:review-mdx
   ```

   **sales engineer** के लिए, "prepare the demo", "run the demo", या "walk through the demo" जैसे ट्रिगर वाक्यांशों का उपयोग करें — प्लगइन स्वचालित रूप से सक्रिय हो जाता है।

</Steps>

## प्लगइन्स को अपडेट करना

इंस्टॉल किए गए प्लगइन को नवीनतम संस्करण में अपडेट करने के लिए:

```text
/plugin update f5xc-docs-tools@f5-sales-demo-marketplace
/plugin update f5xc-sales-engineer@f5-sales-demo-marketplace
```

## अनइंस्टॉल करना

एक प्लगइन हटाएं:

```text
/plugin uninstall f5xc-docs-tools@f5-sales-demo-marketplace
/plugin uninstall f5xc-sales-engineer@f5-sales-demo-marketplace
```

मार्केटप्लेस को पूरी तरह से हटाएं:

```text
/plugin marketplace remove f5-sales-demo-marketplace
```

## टीम कॉन्फ़िगरेशन

अपनी पूरी टीम के लिए मार्केटप्लेस को पहले से कॉन्फ़िगर करने के लिए, इसे अपने प्रोजेक्ट की
`.claude/settings.json` में जोड़ें:

```json
{
  "extraKnownMarketplaces": [
    "f5-sales-demo/marketplace"
  ],
  "enabledPlugins": [
    "f5xc-docs-tools@f5-sales-demo-marketplace",
    "f5xc-sales-engineer@f5-sales-demo-marketplace"
  ]
}
```

<Aside type="tip" title="Shared settings">
  अपनी रिपॉजिटरी में `.claude/settings.json` को कमिट करने का अर्थ है कि
  टीम के प्रत्येक सदस्य को स्वचालित रूप से मार्केटप्लेस और प्लगइन्स प्राप्त होते हैं
  — किसी मैन्युअल सेटअप की आवश्यकता नहीं है।
</Aside>

यह सुनिश्चित करता है कि रिपॉजिटरी में अपने पहले Claude Code सत्र से ही प्रत्येक योगदानकर्ता के पास समान टूल उपलब्ध हों।
