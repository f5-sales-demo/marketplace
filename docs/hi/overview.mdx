एक **Claude Code प्लगइन मार्केटप्लेस** प्लगइन्स का एक क्यूरेटेड संग्रह है जो
Claude Code को नए कौशल, कमांड और एजेंटों के साथ विस्तारित करता है। मार्केटप्लेस टीमों को टूल साझा करने की अनुमति देते हैं ताकि प्रत्येक डेवलपर
बिना मैन्युअल सेटअप के समान क्षमताएं प्राप्त कर सके।

**f5-sales-demo मार्केटप्लेस** [f5-sales-demo](https://github.com/f5-sales-demo)
दस्तावेज़ीकरण प्लेटफ़ॉर्म के लिए बनाए गए प्लगइन्स प्रदान करता है — 20+ रिपॉजिटरी का एक पारिस्थितिकी तंत्र जो एक साझा बिल्ड पाइपलाइन का उपयोग करके GitHub Pages पर Astro/Starlight साइटों को प्रकाशित करता है।

## यह कैसे काम करता है

1. Claude Code में **मार्केटप्लेस जोड़ें** — यह इसे एक प्लगइन स्रोत के रूप में
   पंजीकृत करता है
2. मार्केटप्लेस से **प्लगइन्स इंस्टॉल करें** — प्रत्येक प्लगइन आपके Claude Code सत्र में
   कौशल और कमांड जोड़ता है
3. **टूल्स का उपयोग करें** — प्लगइन्स संदर्भ के आधार पर स्वचालित रूप से सक्रिय होते हैं,
   या आप उनके कमांड सीधे लागू करते हैं

## त्वरित शुरुआत

मार्केटप्लेस जोड़ें और डॉक्स टूल्स प्लगइन इंस्टॉल करें:

```text
/plugin marketplace add f5-sales-demo/marketplace
/plugin install f5xc-docs-tools@f5-sales-demo-marketplace
```

पूरे वॉकथ्रू के लिए [शुरुआत करना](/marketplace/en/getting-started/) देखें।

## वास्तुकला (Architecture)

एक मार्केटप्लेस एक Git रिपॉजिटरी है जिसमें एक या अधिक
प्लगइन्स शामिल होते हैं। प्रत्येक प्लगइन एक एकल इंस्टॉल करने योग्य इकाई में कौशल, कमांड और एजेंटों को पैकेज करता है।

```text
Marketplace (marketplace.json)
└── Plugin (plugin.json)
    ├── Skills (SKILL.md)
    │   └── References (data files)
    ├── Commands (.md)
    └── Agents (.md)
```

- **Marketplace** — रजिस्ट्री। खोज और इंस्टॉलेशन के लिए मेटाडेटा के साथ
  उपलब्ध प्लगइन्स सूचीबद्ध करता है।
- **Plugin** — इंस्टॉल करने योग्य इकाई। इसमें एक या अधिक
  कौशल, कमांड या एजेंट शामिल हैं।
- **Skill** — प्रासंगिक ज्ञान जिसे Claude हाथ में लिए गए कार्य के आधार पर
  स्वचालित रूप से सक्रिय करता है।
- **Command** — एक स्लैश कमांड जिसे उपयोगकर्ता सीधे लागू करता है
  (उदा. `/review-mdx`)।
- **Agent** — एक विशेष उप-एजेंट जो जटिल, बहु-चरणीय कार्यों को
  स्वायत्त रूप से संभालता है।
