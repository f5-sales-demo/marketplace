**Claude Code 外掛集市**是經過精選的外掛集合，用於使用新技能、指令和
Agent 擴充 Claude Code。外掛集市允許團隊共享工具，使每位開發者無需手動設定即可獲得相同的能力。

**f5-sales-demo 外掛集市**提供專為 [f5-sales-demo](https://github.com/f5-sales-demo)
文件平台建置的外掛 — 該生態系統由 20 多個儲存庫組成，使用共享建置管線將 Astro/Starlight 網站發布至 GitHub Pages。

## 工作原理

1. **新增外掛集市**至 Claude Code — 這會將其註冊為外掛來源
2. 從集市**安裝外掛** — 每個外掛都會將技能和指令新增至您的 Claude Code 工作階段中
3. **使用工具** — 外掛會根據情境自動啟動，或者您可以直接呼叫其指令

## 可用外掛

| 外掛 | 類別 | 描述 |
| --- | --- | --- |
| [f5xc-docs-tools](/marketplace/en/plugins/f5xc-docs-tools/) | 生產力 | 用於文件儲存庫的 MDX 內容驗證和審查工具 |
| [f5xc-sales-engineer](/marketplace/en/plugins/f5xc-sales-engineer/) | 生產力 | Sales Engineer 角色框架 — 示範執行、簡報展示、問答及環境管理 |

## 快速開始

新增外掛集市並安裝文件工具外掛：

```text
/plugin marketplace add f5-sales-demo/marketplace
/plugin install f5xc-docs-tools@f5-sales-demo-marketplace
```

參見[快速入門](/marketplace/en/getting-started/)取得完整指引。

## 架構

外掛集市是一個包含一個或多個外掛的 Git 儲存庫。每個外掛將技能、指令和 Agent 打包為單一可安裝單元。

```text
Marketplace (marketplace.json)
└── Plugin (plugin.json)
    ├── Skills (SKILL.md)
    │   └── References (data files)
    ├── Commands (.md)
    └── Agents (.md)
```

- **Marketplace** — 註冊表。列出可用外掛及其用於探索和安裝的中詮資料。
- **Plugin** — 可安裝單元。包含一個或多個技能、指令或 Agent。
- **Skill** — Claude 根據目前任務自動啟動的情境知識。
- **Command** — 使用者直接呼叫的斜線指令（例如 `/review-mdx`）。
- **Agent** — 自主處理複雜多步驟任務的專用子 Agent。
