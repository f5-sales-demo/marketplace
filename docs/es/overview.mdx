Un **marketplace de plugins de Claude Code** es una colección curada de
plugins que extienden Claude Code con nuevas habilidades, comandos y
agentes. Los marketplaces permiten a los equipos compartir herramientas para que cada desarrollador
obtenga las mismas capacidades sin configuración manual.

El **Marketplace de f5-sales-demo** proporciona plugins creados para
la plataforma de documentación [f5-sales-demo](https://github.com/f5-sales-demo)
— un ecosistema de más de 20 repositorios que publican sitios Astro/Starlight en GitHub Pages mediante una canalización de generación compartida.

## Cómo funciona

1. **Agregar el marketplace** a Claude Code — esto lo registra
   como una fuente de plugins
2. **Instalar plugins** desde el marketplace — cada plugin agrega
   habilidades y comandos a su sesión de Claude Code
3. **Usar las herramientas** — los plugins se activan automáticamente según el
   contexto, o puede invocar sus comandos directamente

| [f5xc-sales-engineer](/marketplace/en/plugins/f5xc-sales-engineer/) | Productividad | Marco de persona de Sales Engineer — ejecución de demos, presentación, preguntas y respuestas, gestión de entornos |

## Inicio rápido

Agregue el marketplace e instale el plugin de herramientas de documentación:

```text
/plugin marketplace add f5-sales-demo/marketplace
/plugin install f5xc-docs-tools@f5-sales-demo-marketplace
```

Consulte [Primeros pasos](/marketplace/en/getting-started/) para obtener un
recorrido completo.

## Arquitectura

Un marketplace es un repositorio de Git que contiene uno o más
plugins. Cada plugin empaqueta habilidades, comandos y agentes
en una sola unidad instalable.

```text
Marketplace (marketplace.json)
└── Plugin (plugin.json)
    ├── Skills (SKILL.md)
    │   └── References (data files)
    ├── Commands (.md)
    └── Agents (.md)
```

- **Marketplace** — el registro. Enumera los plugins disponibles
  con metadatos para su descubrimiento e instalación.
- **Plugin** — la unidad instalable. Contiene una o más
  habilidades, comandos o agentes.
- **Skill** — conocimiento contextual que Claude activa
  automáticamente según la tarea a realizar.
- **Command** — un comando slash que el usuario invoca directamente
  (por ejemplo, `/review-mdx`).
- **Agent** — un subagente especializado que maneja tareas complejas de
  múltiples pasos de forma autónoma.
